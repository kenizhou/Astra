The calendar arrives. A Calendar view joins the shell beside Mail with the
agenda and the day, work week, and month grids: occurrence-accurate times,
the now line, visibility toggles per calendar, and event create, edit, move,
and delete through the engine's calendar writes, every write gated on the
calendar's own writability and surfaced with its settling state. One
occurrence of a repeating event is told apart from its series: edits and
deletes ask this event or all events first, a later occurrence moves on its
own clock, and editing a whole series warns where the server would throw
away single-occurrence changes.

Invitations get their card above the reading body: accept, maybe, or decline
with a note, unanswered meetings drawn as holds, declined ones leaving the
calendar, superseded invitations saying so. Where the server cannot pass an
answer on, you are told and offered an emailed reply instead, rememberable
per account.

The calendar's Briefs action generates the day's meeting brief on the
economy model tier, naming the day's meetings from the stored calendar; an
empty day costs no call at all.
