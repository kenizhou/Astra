The delivery batch reaches the surfaces. While every dialled account
stands in outage, a slim banner rides over the shell's top saying the app
is offline and reconnecting (never that something errored), and each
outaged account's group in the folder pane wears a small warning badge
whose tooltip names the account and its reconnect; both leave with the
first successful pass.

Each account's page in the settings carries its own sync section: how far
back mail syncs (the same depth the search note reads), the offline body
cap (headers only, a 256 MiB per-message default, everything, or a custom
figure, the words stating that the figure bounds each message body, never
the account's total), and the poll cadence, 15 to 120 minutes. Every
change writes through one intent that states only the field it changed.

The General page gains the new-mail notifications switch, on by default;
the host reads it at every delivery. And the search results' depth note
is now a link: it opens the settings on the accounts section, where each
account's depth is set.
