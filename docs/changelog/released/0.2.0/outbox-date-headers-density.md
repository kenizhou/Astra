The outbox moves into the folder tree: every account group closes with an
Outbox row badged with the sends still owed, and selecting it switches the
message list to that account's queue with the same per-send actions the
floating panel had (the panel and its rail toggle are gone). The message
list groups its rows under date headers (Today, Yesterday, the weekday
within the last week, then the date; search results stay flat), and a
density switch offers Compact, Normal, and Comfortable row heights from
the View menu's Density submenu or the status bar's cycling label.
