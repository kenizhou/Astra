# The plugin platform's contracts and worker host (SP3a)

The first slice of the plugin platform: the versioned AOM envelope replacing
the interim hook protocol, host-issued handles with typed refusals, the
three-gate router, the supervised out-of-process worker host, the echo
conformance plugin, and the desktop registry with its four commands. The
S/MIME + OpenPGP port is decided built-in (crates/astra-crypto to come), not
a plugin.

Platforms: desktop
Bump: minor
