The calendar becomes a resizable three-pane layout: a rail with a mini-month navigator and a calendar visibility checkbox list, the active grid, and an event detail dock. Clicking an event now picks it for the dock (second click or Escape clears) instead of opening the editor; the dock's Edit opens the editor and its Delete runs the existing delete flow. Dragging over empty time on the day and work-week grids opens the editor prefilled with the dragged slot. The people view becomes a resizable two-card layout, and the person detail is sectioned by value kind with per-account provenance shown for merged people.
