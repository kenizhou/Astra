The settings screen is now a centred modal in the kylins idiom: a vertical
tab rail with an icon per category and an accent bar marking the standing
one, the detail panel beside it, and a footer that says changes apply on
their own beside a Done button. A new Shortcuts page lists the keyboard
shortcuts the app wires today, Ctrl+K's search island first. The General
page gains device-local appearance choices: an accent skin (eight
swatches, Iris the default), a Default/High contrast toggle that swaps in
a pure black-and-white palette with flattened shadows, and a font-size
step of Small, Default, or Large. The three live in localStorage and land
as document attributes, never in the persisted settings block.
