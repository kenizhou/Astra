Silence a sender with junk blocking. The row menu's new "Block sender…"
entry opens a dialog that blocks the sender, so their mail no longer
raises new-mail notifications. Their messages still arrive in your Inbox
exactly as before, only quietly: blocking never moves or files anything.
The dialog can also report the conversation as junk in the same step (on
by default, where your account supports reporting); if the report fails,
the block still stands. Manage your blocked senders in Settings under
General, where you can unblock anyone. Blocked senders are kept on this
device.

Platforms: desktop
