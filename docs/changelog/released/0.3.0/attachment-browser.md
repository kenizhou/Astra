Browse attachments across all your mail in one place: the command palette
gains "Browse attachments", which opens a modal listing attachments grouped by
sender, newest first, with the count and total size beside each. Filter by type
with the mime chips, or open the browse narrowed to one sender. Save As works as
it does in the reading pane, and opening a row jumps to the message it came
from. The footer states how far the browse looked; the first open fetches any
missing sources, bounded per account.

Platforms: desktop
Bump: minor
