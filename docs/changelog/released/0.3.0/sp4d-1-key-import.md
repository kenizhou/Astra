Astra Mail can now import your encryption keys. A new Keys page in Settings
imports your own private key, so encrypted mail you receive opens and reads,
and a peer's public certificate, so their signatures verify and you can send
them encrypted mail. Import by choosing a key file or pasting the key text;
a protected private key asks for its passphrase, which stays in memory only
and is never stored or logged. Your imported keys are listed on the same
page, and the first private key you import becomes your default signing key.
