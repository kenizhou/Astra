Set a message aside and have it come back later: the message row menu
gains "Snooze", which opens a picker offering later today, tomorrow, or
next week. The message moves to a Snooze folder, and at the wake time it
returns to the folder it came from. Snoozes are kept on this device, and a
wake due while the app is closed fires the next time you open it.

Platforms: desktop
Bump: minor
