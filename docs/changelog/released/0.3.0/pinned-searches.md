Pinned searches keep a query for later: the search island's Save search
button saves the live query under a name, and a Saved searches panel beside
the notification bell lists, runs, renames, and deletes them. Running one
opens the island and searches again, exactly as a typed search does. Only
the query is saved, never the scope, and up to twenty searches are kept on
this device. The island's recent history stays session-only.

Platforms: desktop
