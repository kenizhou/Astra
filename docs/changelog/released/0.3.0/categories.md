Astra Mail can now label mail with colour categories. The row menu's
Categorize submenu lists your categories as colour swatches: choosing one
adds it to the selected conversations, or removes it when every selected
conversation already carries it (the Outlook toggle), and the menu stays
open so you can pick several. A colour bar on each row shows its first
category, and a toolbar picker filters the list to one category. The
manager (Manage categories…) defines a category with a name and a colour
from the palette, renames or recolours it, and deletes it with a confirm
that reports how many conversations it was removed from. Categories live
on this device only: they do not sync, are not shared across devices, and
are not mail keywords.
