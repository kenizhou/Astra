A command palette opens with Ctrl+Shift+P (Cmd+Shift+P on macOS): a
keyboard-driven overlay that lists the app's actions, filters as you
type, and runs the chosen one. Navigate mail, calendar, and people, jump
to a folder, compose or reply, act on the selected message, search, open
settings, cycle the theme, toggle the agent and AI panels, sync, and
switch the view. A command whose target is absent shows why it is
disabled. Ctrl+K still opens search; sending stays a human action in the
composer.
