Quick steps bring one-click mail macros: save up to five named steps, each
running one action (archive, delete, mark read or unread, flag or unflag,
or move to a folder) over the selected messages, optionally marking them
read first. A button per step sits on the ribbon, and a Manage editor lets
you create, edit, and delete them. Steps are kept on this device.

Platforms: desktop
Bump: minor
