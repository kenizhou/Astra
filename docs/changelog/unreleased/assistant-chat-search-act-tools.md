The assistant's tool set grows from five mail tools to ten. A new search
tool pages through mail (twenty hits per call, newest first, no bodies)
over the same query language the app's search field takes, and four
confirm-gated actions can mark a message read or unread, set or clear its
flag, archive it, or move it to trash; each action shows an approval card
before anything changes and trashing stays the deepest action available.
The command line gains the matching verbs (`messages search`, `mark-read`,
`set-flagged`, `archive`, and `trash`, the mutating ones with `--preview`
printing the exact edit they would carry). No send tool exists anywhere:
sending stays a human action in the app, and the read tool's output is now
capped at four thousand characters so long bodies cannot flood the chat.
