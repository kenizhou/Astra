Astra Mail can now remind you about a message later. The row menu's
"Remind me…" entry opens a picker offering later today, tomorrow, and
next week; choosing one asks to be notified about that message at the
chosen time. The message stays exactly where it is: a reminder never
moves it and never flags it. At the wake time a "Reminder" notification
fires (even while the window is focused, as long as notifications are
on), and the landing joins the bell's notification history, so clicking
it opens the message. Reminders live on this device; one due while the
app is closed fires at the next launch.

Platforms: desktop
Bump: minor
