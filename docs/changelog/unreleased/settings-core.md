The settings family arrives in the core. Every display setting now
persists before the surface answers: the theme, the 12 or 24-hour clock,
the calendar's display zone, the first day of the week, the calendar
horizon, the reply quoting style, the mailbox grouping, and the default
calendar new events land in. The calendar consumes what is its: the
display zone resolves every floating and all-day row (a zone change
re-expands the diary so nothing silently shifts), the horizon sizes the
window a cold calendar opens with, and a created repeat rule that names
no weekday starts its weeks on the chosen day. The Accounts page gains
its core half: one row per account naming its kind and its dialled legs,
the dav section editor whose save re-dials and installs both legs
without a restart (a failed save keeps the old legs standing and says
so), and Remove account, which takes the stored config, the legs, and
the account's own state together.
