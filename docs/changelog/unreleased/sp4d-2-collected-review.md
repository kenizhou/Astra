Astra Mail now lets you review the encryption keys it collects from incoming
mail. A new Collected keys section on the Settings Keys page lists each key
observed from a peer (via Autocrypt and similar discovery), showing its
fingerprint, the peer's address, where it came from, and its standard. Accept a
key to start sending that peer encrypted mail, or check the fingerprint out of
band first and Accept as verified. Reject a key to remove it and refuse it in
future. Accepting records your trust decision alongside the key, so an accepted
key is ready to use straight away; accepting without verification never lowers a
decision you already made, and a key you rejected stays refused. Only public key
material is shown here, never a private key.
