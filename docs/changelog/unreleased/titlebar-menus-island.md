The title bar gains application menus and a living search island. File,
View, Tools, and Help sit beside the product name: File carries New Mail,
Add account, Sync now, Preferences, and Close Window; View switches the
list between flat and threaded and toggles fullscreen; Tools sets the
theme override (follow host, light, dark); Help opens the settings screen
on its About category. The centred search box is now an ambient island: a
quiet pill at rest that opens on click or Ctrl+K into the same debounced
search with its scope dropdown, submits on Enter, and offers the session's
recent searches while the field stands empty. A presence dot on the pill
follows the agent: muted at rest, pulsing while a turn streams, and in the
warning colour while an approval waits; clicking it opens the agent panel.
