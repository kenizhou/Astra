The desktop shell arrives: a frameless title bar with its own minimise,
maximise, and close controls, a folder pane across every account with unread
badges and expansion the app remembers, and a status bar showing each
account's sync state. Adding a first account opens a setup flow that tests
the connection before anything is stored, shows an untrusted server
certificate's fingerprint for a one-server exception, and starts the
account's first sync.
