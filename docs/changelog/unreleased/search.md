Searching your mail now works from the search box in the title bar. Type and
pause, and every account is searched across all folders except Trash, with
`from:` and `to:` filters beside the words you type. Results show newest first
and follow the list's conversation grouping, a dropdown narrows one search to
the current folder or the current account, and a note beside the count says how
far back the search looked. Escape, emptying the field, or Exit search returns
to the folder you started from.

Platforms: desktop
Bump: minor
