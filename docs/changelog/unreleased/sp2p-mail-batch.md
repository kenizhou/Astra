Folders can now be managed from the folder pane: a right-click offers a
new subfolder, an inline rename, and a delete that moves the folder to
the Trash (inside the Trash itself, the permanent delete, each behind
its own confirm), and Mark All as Read clears the folder's unread rows
in one gesture. Folders drag: onto another folder of the same account to
reparent, onto the account row to become a root, and a message selection
dropped on a folder moves the lot; a drop a folder cannot legally take
is refused before anything is sent. The All Accounts group at the head
of the pane is live: clicking it shows every account's inbox merged,
newest first, and the choice is remembered across launches.

Messages gained a Move to folder submenu over the row menu's account
folders, and a selection now raises its own toolbar with the count,
Select All, Clear, and the batch actions. The composer attaches files:
the attach button opens the file picker, each file stands as a removable
row with its size, and the send carries the bytes. A forward opens
holding the original's attachments, removable one by one, and dragging
files onto the composer attaches documents outright while a picture asks
inline or file. In the reading pane, Save As writes an attachment
through the platform save dialog and reports the saved path or the
refusal, and Download All saves every row.
