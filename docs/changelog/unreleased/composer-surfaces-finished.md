The composer's finishing surfaces. The toolbar gains the font size
control (the four steps from the shared catalog) and two colour pickers
from the app palette, and the three widened marks round trip through the
live editor. The link button becomes an in-place popover (target and
display text, set and remove, Ctrl+K) in place of the window prompt;
typed http, https, mailto, and www addresses become links as the words
leave the caret; and a sentence under the toolbar names the links the
send will degrade, never blocking it. The From field becomes the account
picker over the app-level default send account, seeding and swapping the
per-account signature (authored in Settings' new rich text signature
editor, one slot for new mail and one for replies). Pasting a picture
into the message stages it inline exactly as a drop's inline answer does.
The finishing arc is proven live over the harness wire: a formatted send
round trips with its inline CSS intact, a signature-bearing send lands
both legs, and a link round trips both ways, a good https target
arriving as an anchor while a javascript: target in the sent wire
degrades to plain text.
