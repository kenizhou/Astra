# AI 摘要报与分栏收件箱：Astra Mail 契约

**范围。** 建立在 A1 基础上的 A4 目录能力：账户近期邮件的按需
摘要报、同一窗口上的分析报告、两者落地所依的 AI 文档库与其面板、
由存储分类推导的分栏收件箱与邮件列表开关，以及暴露它们的宿主
命令与 CLI 动词。会议简报保持延期（见下）。约束每一个交付其中
任一能力的界面（目前是桌面宿主、网页阅读壳与 `astra-cli`）。

**原则。** *两份文档都是对应用已持有邮件的一次诚实生成；分栏
则完全不是生成。* 一份摘要报或报告的存在，只因为应用花了它的
一次窗口化调用并把答案存到它所依赖的窗口之下；CLI 读取存储并
拒绝模型类拼写（永不拨号规则，见 `docs/cli.md`）；分栏映射是
对收件扫描存储行的纯推导，花费零次模型调用。

## 文档库

每份存储的文档一行（`ai.sqlite` 迁移 `0010`）：账户、类别
（封闭集 `digest` | `report`，snake_case 线词）、窗口覆盖的时段
对（unix 秒）、一次生成写下的内容、库的创建时间戳、生成回合的
关联 id，因此每行模型衍生内容都可回溯到它的调用。键是
（账户、类别、period_start、period_end）。

**替换与堆叠。** 同一时段的再生成替换该行：写入以自己的删除加
插入在一个事务内运行，因此一个账户每个类别每个时段只持有一份
文档，替换带上新鲜的时间戳与 id（应答在 `regenerated` 标志下
指名这次替换）。变化的窗口（另一个天数，或同一天数在更晚一天
被请求）在旧记录旁边落为自己的行，latest 读取按时间戳再按 id
应答最新的一份。另一个账户把同一时段持为自己的。

## 生成窗口

`digest_generate(account, days?)` 与 `report_generate(account,
days?)` 共享一次收集：天数默认七，钳制在一到三十一（钳制在命令
边界重复一次，webview 绝不说出收集无法对应的窗口），并量化为
整 UTC 日：时段从今天午夜往前 `days` 减一天的那个午夜开启，到
今天最后一秒关闭，无论回合在几点运行。量化正是让存储的
同时段替换成为产品意义上的 regenerate 的机制。

收集读取账户最新的 `DOCUMENT_WINDOW_READ_LIMIT`（200）行，保留
日期落在时段内的行（无日期的行绝不进入无法证明自己所处的
窗口），最新的在前，因此每个类别搭乘的头五条是最新的五条。
每个保留行的纯文本正文经阅读路径解析，每条消息按
`DOCUMENT_BODY_CAP`（2000）字符封顶并带截断标记；取不到正文的
行整条跳过，因此汇总只统计解析成功的邮件。空窗口不发起调用并
存储空内容：面板呈现一个诚实的空。

## 汇总来源与 Sent 过滤

两份文档的类别汇总都构建自收件扫描记录的存储分类：窗口内每条
消息最新的已判定 classify 词，按其提供者键索引。没有被任何扫描
判定过的消息，或其仅有 classify 行是跳过的消息，落入
uncategorised 桶；库中已有的外来词按自己的词搭乘。桶按封闭集
顺序应答，外来词排后，uncategorised 最后，每个桶的列表封顶在
最新的 `DOCUMENT_HEAD_LIMIT`（5）条，而计数说出真实总数。

**Sent 过滤，已记录。** 窗口读取横跨所有邮箱，因此账户自己的
已发邮件会落入覆盖今天的窗口。摘要报的提示词说的是到了什么；
因此摘要报的消息集合把 Sent 邮箱的行整个过滤掉（汇总与列表都
过滤），这是在改写提示词之外选定的诚实修法：没有提示词版本
移动。报告保持自己的形状：它的独立计算统计在代码里统计窗口内
的 Sent 行，其列表搭乘整个窗口（账户自己的发送正是该文档的
主题），邮箱读取失败时统计安全地记零，绝不猜。

## 摘要报

`DIGEST_PROMPT_VERSION` 1，digest 用例，default 层：对汇总与
分组后消息的一次总结调用（inbox-zero 的 `aiSummarizeEmailForDigest`
形状，对整个窗口一次调用，而 inbox-zero 每条消息花一次）。指令、
汇总行与 JSON 输出策略搭乘受信半边；每条消息在自己的非受信
包裹里、处于其受信类别行之下，因此邮件正文绝不能作为指令发言。
补全必须解析为 `{"digest": "..."}`（经共享恢复路径修复一次）；
摘要文本即存储内容。

## 分析报告

`REPORT_PROMPT_VERSION` 1，report 用例，default 层：先在代码里
计算窗口统计（消息数、向下取整到整百分比的未读率、已发数、
各类别计数），然后一次结构化调用，其输出必须解析为三个固定
字段（执行摘要、响应模式、建议），组装为三个标题之下的存储
文档。指令让各节扎根于统计并禁止编造数字；统计是真相，因为
没有模型写过它们。

## 分栏收件箱

零模型调用：分栏经 `SPLIT_MAPPING`（版本 `SPLIT_MAPPING_VERSION`
1）从同一存储分类推导，是钉死的数据，因此决策只活在一处，任何
重新指派或纳入新词都是版本提升加评测重跑：

| 存储词 | 侧 |
|---|---|
| `primary` | `actioned` |
| `newsletter`、`notification`、`receipt`、`cold` | `fyi` |

表未指名的词被排除，没有存储类别的消息根本不进入映射：两者都
只出现在 All。宿主按账户在邮件列表自身的读取深度（加载窗口）
之上提供 `split_map(account)`，随每次 mailbox-list 快照一起拉取，
因此映射跟随核心所服务深度的加载窗口；开关（All / Actioned /
FYI，带计数徽标）本地过滤，绝不跨越 intent，行选择自己的纪律。
会话行不指名单条消息，因此只渲染在 All 之下。

## 面板与 CLI

状态栏的 AI 开关打开文档面板：摘要报与报告两个页签，各读其
类别最新的存储文档（时段标签来自窗口的整 UTC 日，内容原样），
一到三十一天的天数选择器（默认七），以及 Generate，文档出现后
变为 Regenerate，一次请求进行中时拒绝第二次。拒绝的句子渲染在
仍存储的文档之上；一个账户的任何内容绝不落入另一个账户的槽位
（面板的账户纪元守卫）。面板服务所选文件夹的账户，在选中之前
服务第一个已配置账户。

CLI 读取存储且绝不拨模型：`ai digest <account>` 与
`ai report <account>` 应答账户其类别最新的存储文档（时段对、
库的时间戳、生成回合的关联 id、完整内容），没有生成过则为
null。模型类拼写 `ai digest generate` 与 `ai report generate`
先解析后拒绝（退出码 3，账本行指名拒绝），即 `ai style
rebuild` 的先例：生成在面板里运行，agent 读取落下的结果。完整
动词行见 `docs/cli.md`。

## 评测钉与 live 证明

三个常量经评测挂具（`evals/`）钉住：`digest-rollup-head-five`
（汇总的桶顺序、头限制的展示与省略主题、解析后的摘要）、
`report-three-sections`（组装到标题之下的结构化解析）、
`split-mapping-pin`（映射表端到端）。离线全套在 CI 运行；每个
夹具带其版本钉。

门下 live 套件
（`client/desktop/src/ai/live_docs_tests.rs`，在 `ASTRA_LIVE_LLM=1`
加 `ASTRA_LIVE_HARNESS=1` 之下，对运行中的 Stalwart 测试挂具，
一次一个测试）经真实接缝证明服务：对种子笔记的真摘要报（收件
扫描的已判定分类搭乘为汇总来源；真实文本、量化窗口之下覆盖
笔记的存储行、带合理 token 数的 default 层账本行）、解析出三节
的真报告（同一诚实窗口之下）、以及经扫描真实结果服务的分栏
映射，账本行数证明未花任何调用。

## 会议简报，延期

A4 规范的会议简报需要 Astra 尚未持有的日历数据：它们延期到
日历功能切片（其数据依赖），能力行保持未开始并指名该依赖，
绝不静默丢弃。

## 已知缺口

- **分栏映射只服务加载窗口。** 比列表自身读取深度更老的消息不
  出现在任何一侧，与列表本身能显示的行一致；映射随每次
  mailbox-list 拉取刷新，ShowMore 随窗口一同增长它。
- **摘要报的 `regenerated` 标志未在面板呈现。** 存储保持替换的
  诚实，视图应答该标志；面板只渲染呈现字段，因此没有"替换了
  存储时段"的字样。产品需要时只差一个槽位字段。
- **隐藏已打开消息的过滤只重置列表选择。** 阅读窗格保持打开，
  高亮在 All 回来之前渲染在无处。
- **面板在同一角落堆叠而不互斥**（发件箱、agent、AI）：既有
  行为，保持。
- **报告的列表包含窗口内的 Sent 行。** 已记录的决定（摘要报
  过滤，报告保持自己的形状）；已发统计在旁指名计数。
- **两个驱动错误分支未在离线测试钉住**：邮箱读取失败时的统计
  安全零值（已发计数的回退），以及类型化错误之外够不到的
  窗口读取与存储失败。两者都诚实地记录日志，谁都不呈现半份
  文档；一个强制它们的夹具可以补上钉。
