# 日历：Astra Mail 契约

**范围。** 日历表面携带什么，意图族如何经引擎读写日程，如何把序列的
一次出现与序列本身区分开，拖拽在挂钟时间上意味着什么，写入如何门控
与和解，以及会议简报可以做与不可以做什么。对每一个交付日历视图的
表面都有约束力。实质移植自 mail-calendar 的 `calendar.md`，按 Astra
Mail 今日交付的范围裁剪；缺口在文末记录，绝不静默。

**原则。** *日历是服务器拥有、客户端渲染的日程。* 每次写入都是引擎
在幂等键之下的 patch 动词，每次读取都是存储已物化的真相，客户端绝不
发明规则没有产生的出现。

## 表面与快照

`Surface::Calendar` 携带 `CalendarSnapshot`：日历管理器集合（每个日历
的名称、颜色、可见性、`can_write`、默认标记）、可见范围的出现行、写
入状态、邀请机所欠的答复提示，以及现在线数据（快照构建时刻与网格排
布日期所用的 IANA 时区）。快照先发布后通知：表面拉取绝不会观察到存
储不持有的状态。

出现行携带事件的账户与键、日历、标题、解析后的 UTC 起止、全天与重
复标记、出现令牌（见下）、参与状态、该行是否可移动，以及序列编辑警
告。时间是出现精确的：序列的每一行携带自己的时刻，经视界扩展所用的
展开时区解析。快照还发布日历的常设形状（视图种类与导航锚，见下），
所以表面能还原人离开时的样子。

## 事件详情读取

点选事件经宿主命令 `calendar_event_detail` 拉取其详情：名册与完整的
重复规则，都经重建所乘的同一次定向读取、从事件引用点名的主事件读
出。出现行保持精瘦；这份读取是拥挤会议与丰富规则所需两半的唯一载
体。

- **名册**先携带持有者角色的参与者（组织者），其余参与者按存储顺
  序跟在后面，每人一行：姓名（行上没有姓名时为地址）、普通与会者
  之外席位的话语（`chair`、`optional`、`informational`、`contact`，
  外来角色按原文），以及答复状态。列表在前八行封顶，尾部折入计数，
  由表面渲染为拥挤会议的诚实结尾；展开入口是后续条目。
- **规则读回**越过规则自身的形状，旁边是应用从它措辞的句子（门派
  模式：引擎携带规则，应用措辞）：带间隔的频率、规则命名时的星期
  集合、以次数或日期话语表达的结束。措辞词汇之外的规则只越过存活
  部分仍然为真的内容，最退到裸的间隔与频率，绝不是规则不成立的句
  子。until 时钟在秒非零时把秒也说出来，所以分钟之内的边界既不会
  读成整分钟，也不会读成当日之末。
- 编辑器**只读**携带这两半：本切片的编辑器改不了宾客名单，也措辞
  不了规则；名单在那里，让人看见自己在写给谁，句子是读，创建路径
  的选择框仍是可编辑词汇。

## 持久化形状

日历的形状（视图种类与导航锚）作为偏好持久化并在启动时还原。点名
视图的 `set_range` 记录它；`set_date` 记录锚；两者都不点名的写入不
动常设偏好，被拒绝的写入保持常设形状（快照在每次重建时发布它，表
面跟随发布）。过去的锚精确还原：启动种子把窗口播在锚自己的那一
周，所以日程画在人离开的那一天，不是今天。视界的持久设置自成一行，
保持不变。

## 全天横幅

跨天的全天出现渲染为全天车道上横跨其各天的**一条**横幅，列被连
接，窗口裁剪之处在裁边标记向隐藏日子的延续；共享日子的横幅在各自
车道里堆叠。定时出现无论跨多少天都不变成横幅：它保持钳制的块，因
为横幅是全天概念。月格把跨天全天出现在其开始的那一天只落一枚短
签，所以溢出计数数的是出现而不是重复。

## 窗口与视界

日程渲染表面设定的窗口（`SetRange`），由引擎的出现扩展按块加宽。记
录已扩展范围的视界水位**跨账户共享**：一次加宽只有在**每个**账户的
存储都已扩展覆盖该范围之后才推进水位，任一账户拒绝即回滚水位。存储
比水位宽是安全的，因为出现读取按调用者的窗口取界；水位比存储宽则不
安全，因为其中的后续范围会自信地渲染为空，且同步无法修复。被拒绝的
加宽是一次失败，按失败回答，绝不是自信的空。

## 意图族

`Intent::Calendar` 携带该族，serde snake_case，只增不改：

| 意图 | 含义 |
|---|---|
| `refresh` | 同步窗口内的日历并重新发布 |
| `set_range` | 设定可见窗口（起点、天数、可选其所服务的视图） |
| `set_visible_calendars` | 为重建切换日历可见性 |
| `create_event` | 引擎的草稿，落在行声明可写的日历上 |
| `update_event` | patch 动词：标题、备注、地点、时钟、规则 |
| `move_event` | 一次拖拽：哪些边、整天数、分钟数、可选的出现 |
| `delete_event` | 整个序列，或令牌命名的一次出现 |
| `respond_to_invitation` | RSVP（见邀请契约） |
| `set_date` | 导航锚（今天、选定的日期） |
| `answer_reply_prompt` | 邮件回复回退的问题，被回答 |

## 出现令牌

重复事件的一次出现以其**原始起点**命名，为事件自身时区的挂钟时间。
令牌对表面刻意不透明：它是"你拖的那个周二"的标识符，不是用来计算的
时间。命名一次出现的写入先证明令牌是快照铸造的：在存储窗口上重铸并
比对；过期的令牌按类型拒绝且不写任何东西，因为在规则从未产生的时刻
拆分序列会损坏它。

## 此事件还是全部

序列还是一次出现由用户决定，绝不默认：编辑与删除路径先询问后跨越，
写入携带答案。

出现级编辑要声明时钟。引擎的 CalDAV 路径拒绝缺少两端的首次覆盖写
入，因为副本会继承主的槽位（主的时间是*第一次*出现的时间）。规则：

- **两端都不声明的宿主是在做纯内容编辑。** 应用从存储的事件补齐两
  端（保持不变），只有它持有事件的时区。
- **只声明一端的宿主被按类型拒绝**：猜测缺失的一端会重定时该出现。
- **一次移动声明两端**，拖拽被转换为它们。

## 拖拽币制

拖拽是挂钟上的整天数与分钟数，应用于事件**自身**的时区：增量对浮动
与全天事件精确；对带时区事件等于网格表达的拖拽语义。靠后的出现在
**自己的**时钟上移动，不在主的时钟上；引擎写的覆盖从 patch 取新时
间，为靠后出现平移主的边界会把块落到序列的起始槽位。

调整大小在十五分钟下限处钳制（全天事件为一整天）；全天拖拽携带的分
钟被丢弃而不是舍入到相邻日期。超过 366 天的拖拽被拒绝而不是转换，
因为民用日期算术在可表示的日历时间之外饱和。

## 序列警告

在服务器会丢弃单次修改之处编辑整个序列，写入跨越前先警告。警告只在
两个事实同时成立时触发：行的覆盖存续说明服务器丢弃单次修改，**且**
确有可丢弃的覆盖存在。任一事实单独成立都不警告。

## 写入门控与写入状态

每次写入在触碰引擎之前先咨询该行日历的 `can_write`；只读日历不提供
写入入口并按类型拒绝写入。写入按账户呈现状态：`writing`，然后落定，
或带重试的 `failed`。失败的写入重新发布存储的真相；拒绝之后表面绝不
断言未确认的移动。乐观的网格移动由下一次发布清除，无论落向何方。

## 会议简报

当天的会议简报按请求生成（宿主命令 `calendar_brief_generate`，应用的
`generate_meeting_brief`），运行在 Economy 层，经用例注
册表解析（调用点绝无字面量），调用前铸造一个关联 id 并记入台账行。
会议从存储重读，绝不用缓存的快照字段；当天的视界先加宽，加宽被拒则
简报失败而不是自信地回答无会议。会议内容先走脱敏路径再进不可信包
裹；时间保持可信。读取后无会议的当天回答定义好的无会议状态且**分文
不花**。简报按请求重新生成，不缓存。

## 已知缺口

- **编辑期的规则重构缺失。** 创建路径提供重复选项；编辑路径降级为只
  读而不是重写无法完整读回的规则。
- **可见窗口仅靠控件移动。** 工具栏箭头、今天、视图切换与月格日期单
  元设定范围；滚动网格不设定。
- **网格拖拽移动整块。** 调整大小由事件对话框的结束边编辑提供，不由
  网格边把手提供。
- **名册在八行封顶，没有展开入口。** 三十人的会议显示八个名字与折入
  的计数；看到第九位与会者是后续条目。
- **规则读回只措辞受支持的词汇。** 奇异的规则退到诚实的间隔加频率形
  状，而不是错误的句子。
- **没有周期刷新计时器；启动时的离线日程是后续条目。** 人离开的形状
  现在启动时还原；进入与重获焦点时刷新，第 78、79 行保持开放。
- **简报不持久化。** 每次请求重新生成。
