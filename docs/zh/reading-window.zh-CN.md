# 邮件独立窗口：Astra Mail 契约

**范围。** 在阅读窗格之外，于自己的操作系统窗口中打开一封邮件。
对每一个交付阅读视图的表面都有约束力。该窗口完全沿用编写器弹出
窗口的模式；缺口在文末记录，绝不静默。

**原则。** *一个打开的阅读状态。* 宿主同一时刻只持有一个打开的
邮件，也不存在任何针对单封邮件的正文命令，因此该窗口经阅读窗格
行点击所发送的同一条受保护的打开路径打开其邮件，窗格则跟随窗口
的打开：任一阅读侧发起的已读标记只落一次，窗格的快照显示该状态
持有的任何邮件。

## 窗口

邮件行的 Open in New Window 与阅读窗格自己的溢出菜单，都打开一个
无边框、居中、可调整大小、以主题为标题的操作系统窗口。URL 以各自
独立的参数携带邮件标识（账户与提供商键，因为两者都是不透明字符串，
无法保证任何分隔符不出现在其中）、列表所在文件夹的键（窗口的
非垃圾动词据此判断上下文），再无其他。窗口 id 每次打开时铸造，
标签落在窗口能力授予的 `message-*` 通配符之下：与编写器窗口相同的
控件（拖动、最小化、最大化、关闭、监听），绝无更多。

该窗口渲染阅读窗格渲染的完整阅读视图，基于自己的快照拉取：带
动词的信头、邀请卡片、AI 表面、处于当前缩放档位的正文、附件，以
及快速回复条。每个窗口只注水一次：打开意图先落，随后的阅读拉取
读到的正是该窗口对应的那封邮件，设置与账户树的拉取随之加入。

## 关闭语义

该窗口在其邮件关闭时关闭：打开的阅读状态不再持有该窗口的邮件，
即是关闭，无论它如何发生（关闭意图、刷新后邮件消失、另一个阅读侧
打开了别的邮件）。只有在该状态曾经持有过该邮件之后，关闭才会武装
（heldOnce 武装），因此在挂载与注水自身的应用之间落地的广播，无法
关上一个从未打开的窗口。

## Tauri 之外

普通浏览器没有宿主可供开窗，因此该动词改为在窗格中打开邮件，
即始终存在的内联阅读器。

## 已知缺口

- **同时只有一个窗口。** 宿主持有一个打开的阅读状态，因此打开第二
  封邮件会使第一个窗口关闭；独立的每窗口阅读状态是以后的宿主半边。
- **窗口内不能导航。** 窗口持有一封邮件；移到另一封意味着从列表
  打开它，窗格随之跟随。
