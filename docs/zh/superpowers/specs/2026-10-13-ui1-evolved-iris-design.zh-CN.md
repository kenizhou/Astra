# UI1 Evolved Iris 设计(评审副本,非规范性)

日期:2026-10-13
状态:提议
父证据:2026-10-13 的设计审计
(`~/.gstack/projects/kenizhou-Astra/designs/design-audit-20261013/`)、
`client/web/.gstack/designs/redesign/` 中的十二页演示,以及已记录的
选择(决策 01bb418e:四个表面均选 A,Evolved Iris)。
移植契约:无直接对应;本切片是 SP2m 及以后各表面将取用的视觉系统,
先于它们落地。

## 1. 目的

把后续切片赖以建设的设计系统作为一个连贯变更落地,而不是按表面逐渐
堆积。两轮审计给当前外壳评了 A-,并将五项发现推迟,因为它们是系统
级决策而非一行修复:密度标尺(FINDING-003/004)、空状态族
(FINDING-005),以及 SP2p 及以后无论如何都需要的模式(账户色点、
AI 批准语法)。用户比较了十二页演示上的三个方向,选中了 Evolved
Iris:把当前方向做完整。本切片交付它。

## 2. 决策

- **D1(密度轴)**:把 `data-font-size` 档位推广为文档根上的
  `data-density` comfortable/compact 轴,由 `appearance.ts` 在既有
  字号档位旁持有。同一把标尺驱动行高(舒适 28px、紧凑 24px)、可点
  击下限(28/24px,任何地方都不得低于 24px)、窗格内边距,以及消息
  行的三行/单行切换。审计推迟的低于 24px 的目标(折叠箭头、视图
  标签、轨道图标、迷你月历格子)在同一变更中归入该轴;14px/16px 正
  文之问由此成为一个面向用户的设置,而不是固定值。设置 General 页
  在 Font size 旁新增 Density 分段控件。
- **D2(字体排印之声)**:一款打包的可变字体作为应用资源发布,排
  在 `--font-ui` 系统栈之前,保持离线保证(资源随应用打包;系统栈
  仍是回退)。候选为 OFL 字体;具体字体在实现切片中对照演示页并排
  选定。表格数字(`font-feature-settings: 'tnum'`)应用于每一处计
  数、时间戳与时长。
- **D3(一个状态族)**:单一的 `EmptyState` 组件(图形块 + 消息
  + 可选主操作,即演示中的 `.state` 模式)替换所有裸空状态:列表
  窗格的"Select a folder"、日历与联系人的空态;每个表面的加载骨
  架与内联错误采用同一族。设置的保存错误(具体、在源头、琥珀色)
  即错误模式,予以推广。
- **D4(多账户模型)**:文件夹窗格获得按账户的色点(在强调色皮
  肤旁设一组固定的八色账户调色板)以及带未读徽章的 Unified inbox
  行,先于 SP2p 的 All Accounts 组;视觉语言在此落地,行为在其
  切片落地。
- **D5(AI 语法)**:每个 AI 纸片带其出处("from this thread")、
  其状态(pending 为虚线、approve 为强调色边框),以及始终显式的
  approve 操作,与 sidecar 的失败即关闭姿态一致。单一 `AiChip` 组
  件服务阅读窗格、撰写器工具栏与摘要。
- **D6(动效令牌)**:时长标尺(100/120/140/160ms),以及
  `--ease-spring` 只属于命令面板的规则;行选择以 120ms ease-out;
  在 `prefers-reduced-motion` 下一切降为即时。本切片不新增其他动
  画。
- **D7(上手即第一分钟)**:账户设置的检测步骤采用演示形态:信
  任决策是该步骤的标题(点名未加密一跳,点名加密两腿),approve
  操作是主按钮。文案遵循 `a-onboarding.html`;信任规则本身不变。

## 3. 测试

- 每个表面的 vitest:密度轴凭一个属性切换所有行高与点击下限;
  `EmptyState` 渲染其三部分;`AiChip` 渲染出处与两种状态;设置页
  新增 Density 控件并经 `appearance.ts` 的 localStorage 路径持久化。
- Rust 不动:无意图、快照或线形变更;底线
  (`cargo clippy --workspace --all-targets -- -D warnings`、
  `cargo test --workspace`、门禁)必须无需改动保持绿色。
- 可视化验证:对夹具台架按表面运行 `/design-review`,两种密度、两
  种主题各一遍;审计推迟的发现要么关闭,要么作为已作答记录。
- 浅色主题在本切片中获得首次完整审计(此前两轮审计仅跑深色;已在
  基线记录)。

## 4. 已知缺口(预先记录)

- 夹具台架只服务静置快照,因此选中态、阅读态与模态在构建的应用中
  验证,而非台架;台架事件注入是单独的后续任务。
- 打包字体在实现切片中选定;无论选哪款,CJK 回退保持系统栈
  (`PingFang SC`、`Microsoft YaHei`、`Noto Sans SC`)。
- B(Editorial)与 C(Command)的元素按决策不随本切片发布;衬线
  阅读栏与命令面板是单独的后续选择,不属于本切片。
- 能力矩阵不动:本切片不改变任何契约,只改变视觉系统;SP2p 的
  All Accounts 组行保持 ⬜,直到其行为落地。
- 高对比模式的扁平化令牌块不受密度轴影响(它只覆盖系列与阴影令
  牌),无需自己的密度变体;已记录,而非静默略过。
