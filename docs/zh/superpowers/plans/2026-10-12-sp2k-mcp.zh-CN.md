# SP2k MCP 服务器实施计划

> **给代理工作者：** 必须使用 superpowers:subagent-driven-development（推荐）
> 或 superpowers:executing-plans 按任务逐条执行本计划。步骤使用复选框
> （`- [ ]`）语法跟踪。

**目标：** 端到端交付 MCP 服务器：带两扇门分界的查询层、带正文规则与台
账的工具面、带对端核验的命名管道监听器、stdio 中继二进制、带账户允许清
单的 Advanced 设置面板、e2e 与实测证明、以及记录两处偏差的契约文档。

**架构：** astra-app 在既有分发（写入）之旁拥有查询层（什么也不改的读
取）；新的 astra-mcp crate 拥有服务器、工具 schema 与 JSON-RPC 帧；一
个中继二进制把 stdio 桥接到管道；桌面宿主运行监听器，Advanced 面板做门
禁。
**技术栈：** 现有工作区加命名管道/套接字传输（由调研定夺）；无协议依赖
（JSON-RPC 帧手写并以向量钉住，中继不识协议）。
**规范：** `docs/superpowers/specs/2026-10-12-sp2k-mcp-design.md`

## 全局约束

- 各切片通用的内部规则：SPDX、500 行上限、deny-everything lint、提交前跑
  gate（直接退出码）、约定式提交、无破折号、英式英语、zh 镜像同提交、
  线协议只增。
- 常设指令：PR 合并即自动继续；SQUASH AND MERGE；10 分钟作者窗口。
- Astra 的安全规则手册有约束力：不向代理开放发送类动词；fail-closed 姿
  态；台账纪律。
