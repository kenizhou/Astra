# 命令面板：契约

**范围。** 桌面外壳里键盘驱动的命令面板：列出应用各项动作、边输入边
过滤、运行所选动作的全局浮层。kylins 增补中的第一个（创始规则把栈/UI
的优势给 kylins）；是增补，不是 mail-calendar 的对齐债。约束 web 客户端
的外壳。纯 UI：不新增 wire 类型、不新增 intent，也绝不发送。

## 面

一个自定义浮层，不用库。一个文本输入框罩在命令的扁平列表上：

- 过滤是对标签的大小写不敏感子串。无模糊评分、无最近使用、无分组标题
  （参考实现也不交付这些）。
- ArrowUp 与 ArrowDown 环绕；选择随列表收缩而钳制。Enter 运行所选命令
  并关闭。Escape 与背景点击关闭。每次打开重置查询与选择。
- 无障碍：`role="dialog" aria-modal`，输入框的 `aria-controls` 与
  `aria-activedescendant` 接到活动选项，`ul role="listbox"` 与
  `li role="option" aria-selected`，一个空状态。打开时焦点移入输入框，
  关闭时移回。
- 目标缺失的命令被禁用并给出原因（诚实禁用惯用法）：该行展示原因、
  携带 `aria-disabled`、拒绝运行。每个命令在调用时重新解析其目标，若
  目标自列表渲染后消失则安全空操作。
- 浮层处于 `--z-modal` 层并挂载在外壳浮层尾部最后，故打开时位于其他
  模态（设置、账户设置）之上。其入场动效用 `--ease-spring`，设计系统
  为面板独占保留的令牌。

## 绑定

**Ctrl+Shift+P**（macOS 上 Cmd+Shift+P）切换面板。opener 是一个尊重
`event.defaultPrevented` 的 document keydown。**Ctrl+K 仍归搜索岛**；
面板绝不偷走它。该绑定列入设置里的快捷键清单，每个新快捷键都必须在
同一变更里加入该清单。

## 命令

每个命令映射到应用已交付的动作；面板不新增 intent。命令集：

- **前往**：Mail、Calendar、People；Inbox、Sent、Drafts、Archive、Trash
  （当前账户的 role 文件夹，如文件夹面板那样选中并派发）；统一收件箱。
- **撰写**：新邮件（ribbon 的无账户门控）；对已打开邮件的回复、全部
  回复、转发（转发携带原件附件），无邮件打开时禁用并给出原因。
- **邮件动作**作用于所选行：标为已读 / 未读、加旗 / 去旗、归档、删除
  （移入回收站），无行选中时禁用并给出原因。
- **搜索邮件**：通过一个小的注册 opener 接缝打开搜索岛（岛在挂载时
  注册、卸载时清除；无岛挂载时调用空操作）。
- **应用**：设置；添加账户；循环主题（经设置 intent，以便持久化）；
  切换代理面板；切换 AI 文档面板；立即同步邮件。
- **视图**：扁平 / 线程化；阅读窗格 右 / 下 / 关。

**发送绝不成为命令。** 发送纪律是确定性且仅人工的（规则书，Security）：
发送走撰写器自己的提交路径，面板不提供任何发送类动词。

## 已知缺口，记录而非静默

- 完整快捷键引擎（可重映射绑定、序列、持久化覆盖）不在内：面板交付
  一个固定绑定，形态为将来的 keyMap 保持开放。
- 快捷键帮助浮层是单独的 backlog 项；静态的设置快捷键清单如今承载
  该列表。
- 被推迟的命令，命名而非静默：逐账户切换、发件箱导航、列表密度与
  过滤、标为垃圾邮件、永久删除、撤销（Astra 无对应物）。
