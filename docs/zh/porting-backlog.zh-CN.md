# 移植待办：通往功能对齐之路

**状态。** 一份活路线图，不是契约：它点名在锁定参考基线、激活每夜上游
同步之前还剩什么。行级真相在 `capabilities.md`；本文把行指派给切片并记
录顺序。它随退役其一部分的切片在同一变更中移动。

**如实清点的规模。** mail-calendar 交付 132 行能力，全部完成。Astra 今
日：少数干净交付，大多数部分交付，还有一条长尾未启动。kylins 另有一类
Astra 矩阵尚未点名的功能；按奠基规则 mail-calendar 在功能契约上优先，
所以那些是所有者挑拣的增项，不是对齐欠账。

## 切片 ladder，按序

| 切片 | 范围 | 退役 |
|---|---|---|
| SP2k（进行中） | MCP 服务器：查询层、工具面、管道与中继、Advanced 面板 | MCP 行 |
| SP2l | OAuth 地基：浏览器 PKCE 登录、令牌存储与刷新、重连横幅、过期登录报告 | OAuth 脚手架各行 |
| SP2m | Microsoft Graph：邮件读取与操作、发送、日历读写、目录 | Microsoft 各行 |
| SP2n | Google 原生 API：邮件与日历 | Google 各行 |
| SP2o | JMAP：含正文的邮件、发送、日历读取；JMAP OAuth 与续期（harness 说 JMAP，落地当日即可实测） | JMAP 各行 |
| SP2p | 邮件批次：文件夹管理（创建、改名、移动、删除、拖拽）、双向附件、多选操作、统一 All Accounts 组、移入文件夹 | folder-pane 与 list-selection 各行 |
| SP2q | 撰写收尾：格式工具栏、链接、内联与附加文件、带每账户默认的签名、From 选择器与默认发件账户、mailto: 入口 | composer 各行 |
| SP2r | 投递批次：IMAP IDLE 推送与轮询、后台同步、新邮件通知、离线优先正文、每账户抓取深度与大小 | sync 各行 |
| SP2s | 阅读批次：消息独立窗口、另存为 .eml、打印、阅读缩放与重排、垃圾邮件报告、滑动操作 | reading 各行 |
| SP2t | 平台批次：诊断与日志查看器、经同意的分析、隐私表面、OS 集成、本地化、设备时区提示 | platform 各行 |
| SP2u | 日历与联系人收尾：参会人列表、完整规则读回、跨天横幅、持久化形状、邮件行上的联系人照片 | 零散各行 |
| SP2v | 服务器提供处的 IMAP/SMTP OAuth 登录 | mail-oauth 行 |

SP2v 之后：锁定阶段评估（每行或交付、或部分交付带记录缺口、或显式决
定），然后 22:00 上游同步激活。

## 本待办所欠的决定

- **Allodia 商业表面**（厂商账户、订阅视图、下一设备账户列表）是
  mail-calendar 自己的业务层。Astra 在锁定阶段前记录显式 N/A，或所有
  者决定移植；绝不可作为静默未启动行立着。
- **kylins 增项**（命令面板、置顶与固定搜索、稍后处理、快捷步骤、清
  扫、退订、VIP、watch-replies、悬停操作、旗标提醒、垃圾拦截、分类与
  分级与条件格式、引用折叠、快捷键帮助、附件浏览器、通知历史、crypto
  插件表面）等所有者挑拣；每个挑选在此 ladder 旁成为自己的切片。
- **AI 余项**：带工具预算的助手聊天是唯一未启动的 inbox-zero 行；放
  哪里由所有者定。

## 已知缺口

- 切片 ladder 是形态估计，不是规模承诺：切片可随其规范落地而拆分或合
  并，本表随之移动。
- kylins 增项按设计不排期；上面的一切不依赖它们。
