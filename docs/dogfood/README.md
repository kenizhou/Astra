# Dogfood notes

One file per real-day run, named `YYYY-MM-DD-<slug>.md`. Free-form, but
every first-run completion notes the detection step: the D7 hypothesis
(trust-first raises completion) is falsified if abandonment or hesitation
shows up there in the next five first-run notes. This directory is a
working log, not a contract; the doc-sync gate does not mirror it.
